# DataLogger Specification Pack

This pack contains the finalized requirements and architecture for the C++17 Visual Studio 2019 DataLogger project.

## Files

- `AI_CONTEXT.md` — high-level Codex context.
- `docs/01_REQUIREMENTS.md` — numbered requirements.
- `docs/02_ARCHITECTURE.md` — architecture and API model.
- `docs/03_DESIGN_DECISIONS.md` — decisions and justifications.
- `docs/04_PROJECT_SUMMARY.md` — readable project summary.
- `docs/05_IMPLEMENTATION_PLAN.md` — implementation sequence.

## Intended use

Give `AI_CONTEXT.md` plus the `docs/` folder to Codex before generating the actual C++ project.
